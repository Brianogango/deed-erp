# Validation rules (prototype)

| Gate | Demo behaviour |
|------|----------------|
| Duplicate confirm | Dialog only; no SO write |
| Invalid serial | Toast “Invalid serial” |
| Duplicate serial | Toast “Duplicate scan” |
| Over-pick qty | Input max bound (qty line) |
| Over-invoice | Remaining column shown as 0 |
| Partial delivery | Status pill Partial |

Production enforcement remains in store/API — unchanged in this phase.
